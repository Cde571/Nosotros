NOSOTROS. 0.3 · Windows x64

Un espacio privado para dos, con interfaz oscura sin barra blanca.

1. Abre Ajustes y elige tu nombre, tu foto y su fecha especial.
2. Crea su espacio y comparte el código con tu pareja.
3. Tu pareja introduce el código y elige su propia foto.

La conexión por código requiere un instalador preconfigurado con el servicio
Supabase del propietario. Este paquete conserva el modo local si falta esa
configuración. Nunca introduzcas una clave secreta en la aplicación.

Los accesos rápidos se guardan en este dispositivo. Asocia un correo desde
«Recuperar o proteger mi acceso» para poder entrar desde otro equipo.

Las X de la app ocultan la ventana en la bandeja del sistema. Para cerrar
completamente, usa Salir en el icono junto al reloj.

El instalador no tiene firma digital. Requiere Microsoft Edge WebView2 Runtime.
El código, las pruebas y las instrucciones están en el README del proyecto.
